Política de Privacidade do LivePresenter

Última atualização: 28 de outubro de 2026

O LivePresenter é um aplicativo para Windows que roda no computador do usuário. Esta política explica quais dados ele usa, principalmente quando o usuário conecta uma conta Google para sincronizar a biblioteca com o Google Drive.

Dados guardados no computador

Apresentações, playlists, temas, mídias, fontes, Bíblias e configurações ficam no próprio computador do usuário, na pasta de dados do aplicativo. O LivePresenter não tem servidores próprios e não envia esses dados para nós nem para terceiros.

Dados do Google

A conexão com o Google é opcional e começa só quando o usuário clica em “Conectar conta Google”. O LivePresenter pede estas permissões:

  • Google Drive (drive.file): criar uma pasta “LivePresenter” no Drive do usuário e ler, gravar e mover para a lixeira somente os arquivos que o próprio LivePresenter criou nela. O LivePresenter não tem acesso a nenhum outro arquivo do Drive.
  • E-mail da conta (openid, email): mostrar nas configurações qual conta está conectada.

Como os dados do Google são usados

  • Os arquivos da biblioteca são enviados e baixados diretamente entre o computador do usuário e o Google Drive dele. Nenhum dado passa por servidores nossos.
  • O token de acesso fica guardado só no computador do usuário, criptografado pelo Windows.
  • Os dados do Google não são vendidos, compartilhados, usados para publicidade nem usados para treinar modelos de inteligência artificial.
  • O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como remover o acesso e os dados

  • No LivePresenter: Configurações → Sincronizar → Desconectar. Isso revoga o acesso e apaga o token do computador.
  • Na conta Google: myaccount.google.com/permissions.
  • A pasta “LivePresenter” no Google Drive pertence ao usuário e pode ser apagada por ele a qualquer momento.
